# Market-comparison program — do not claim superiority without measured parity

As of 2026-11-22, the evaluated comparison class includes OpenAI Agents SDK, OpenHands, LangChain, Dify, n8n, and A2A protocol implementations. These have substantially more complete hosted functionality than this patch. The current kernel does **not** claim to outperform any of them. The competitive hypothesis is that an *Atlas-specific* source/rights/ontology/lab evidence contract may provide advantages on cross-domain scientific provenance and revocation discipline **after valid head-to-head evaluation**.

## Pre-registered independent comparison

| Dimension | Independent test (same fixtures, same rights, budget and model) | Passing acceptance |
|---|---|---|
| Citation/source provenance | 100 exactly pinned sources plus 100 false labels | 0 false accepted semantic joins; complete source/edition citations |
| Rights and privacy | two principal/tenant worlds, revocation at READ, RETURN, queue and chunk | 0 protected cross-mode reads; no new controlled sends after W |
| Genuine collaboration | real opt-in accounts, distinct conversation attestations and room seq | independently attributable A→B→A′; never count synthetic peers |
| Scientific validity | calibrated controls, held-out conditions, uncertainty and units | no promotion from simulation to measured result; blinded holdout reported |
| Deterministic reproducibility | fresh isolated runs with identical pinned inputs | all packet hashes/units reproducible or explained |
| Developer success | same benchmark software repair repo and CI | measured success rate, p95 latency, human time, rollback |
| Cost/energy | same task, backend, caps, infrastructure | measured dollars/valid task and CPU/energy consumption |
| Availability & accessibility | current deployed host, 3D/2D/keyboard/screen readers | measurable WCAG and performance acceptance |

**Baseline status:** no competitor benchmark was run by this patch; each outcome is **NOT MEASURED**. Local tests here are contract validations, not market comparisons. The first actual comparison should run on *one small GitHub fixture* and *one public scientific data fixture*, with the same task and no privileged Atlas-only metadata.

## Chosen differentiation (hypotheses)

1. Reversible, non-canonical A+B=C hypotheses with mandatory falsifiers may be useful in interdisciplinary research.
2. A strict split between public reference/identity, Work permissions and voluntary private modes may reduce accidental ingestion.
3. One experiment/evidence contract across QPU simulation, plasma, materials and engineering data may improve auditability.

Each hypothesis has a plausible failure mode: excessive ceremony/latency, missing upstream features, inadequate scientific calibration, missing host attestation or gaps relative to competitors. These objections must be retained in review.
