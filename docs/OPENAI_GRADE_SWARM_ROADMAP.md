## Acceptance Standard

An OpenAI-grade swarm artifact must be:

- receipt-backed
- provenance-labeled
- status-labeled
- testable or explicitly non-testable
- candidate/canon/deployment state explicit
- human-root gated for canon/deployment
- non-destructive under INV-0
- no identity fusion / no merged mind
- forkable by a reviewer
- understandable from a single README or proof graph
