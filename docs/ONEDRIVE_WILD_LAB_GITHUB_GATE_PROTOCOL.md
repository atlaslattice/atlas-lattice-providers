# OneDrive Wild Lab → GitHub Gate Protocol

```text
STATUS: CANDIDATE PROTOCOL NOTE
CANON: NO
DEPLOYMENT: NO
AUTHORITY: NONE
HUMAN-ROOT: REQUIRED FOR PROMOTION
```

## Core Insight

OneDrive is the wild creative prototype space.

GitHub is the gated consistency, protocol, review, and canon-discipline space.

This gives the organism two complementary surfaces:

```text
OneDrive / Copilot = fast creative laboratory
GitHub = receipt-preserving public substrate
Eight Gates = promotion firewall
Human-root = final authority
```

## Working Rule

```text
Be wild in OneDrive.
Be disciplined in GitHub.
Nothing crosses from prototype to public/canon without gates.
```

## Flow

```text
OneDrive creative draft
→ Copilot-assisted prototype
→ source/hash/status receipt
→ GitHub candidate artifact
→ Eight Gates scan
→ review lane
→ human-root decision
→ only then promotion
```

## Non-Authority Reminder

```text
OneDrive visibility ≠ approval
Copilot generation ≠ validation
GitHub commit ≠ canon
receipt ≠ approval
dashboard ≠ deployment
simulation ≠ proof
```

## Why This Works

OneDrive can hold high-velocity messy creativity without forcing every exploration into public repo discipline too early.

GitHub then receives only bounded, labeled, receipt-backed candidate artifacts.

The Eight Gates prevent accidental promotion, placeholder source, secret leakage, overclaiming, and local-only proof confusion.
